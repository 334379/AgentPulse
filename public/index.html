📡 数据采集与接入协议 (API SDK)

本监控台开放标准 HTTP 上报端点，任何 Agent 框架（LangChain, LlamaIndex, AutoGen, CrewAI 或原生 API）均可零侵入打点。

Python 客户端上报示例 (流式输出/单次调用)：
import requests import time def report_metric(agent_id, prompt_tokens, comp_tokens, duration_sec, ttft_ms=120): url = "http://127.0.0.1:4190/api/metrics/report" payload = { "agentId": agent_id, "promptTokens": prompt_tokens, "completionTokens": comp_tokens, "durationSec": duration_sec, "ttftMs": ttft_ms, "status": "success" } requests.post(url, json=payload, timeout=1.0) # 例如在 Agent 执行完成或流式回调结束时调用： report_metric("agent-coder", prompt_tokens=520, comp_tokens=340, duration_sec=4.2)
cURL 快速测试命令行：
curl -X POST http://127.0.0.1:4190/api/metrics/report \ -H "Content-Type: application/json" \ -d '{"agentId":"agent-researcher","promptTokens":300,"completionTokens":180,"durationSec":2.1,"ttftMs":95}'
